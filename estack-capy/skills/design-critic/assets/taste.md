# Evan's design taste

Rules earned from his own feedback. A reviewer proposes each rule and adds it only after Evan approves it. Each rule is a generic UI or design principle that applies across features and screens, such as spacing, hierarchy, type, color, or states. Never a feature-specific fix, copy, or behavior; that feedback stays a one-off fix. Empty until he approves one. Do not invent a rule.

## Format

Each rule is one sentence a screenshot can settle, followed by where it came from.

```md
### R1. <what the rule forbids or requires>

- **Check:** <how a reviewer confirms a violation from a screenshot>
- **Source:** "<Evan's words, quoted>", <round or thread>, <date>; approved by Evan, <date>
- **Fired:** <count of times a built screen broke it>
```

Number rules in the order they were earned and never reuse a number.
