# <Feature / Bug / Improvement Name> PRD

> **Agent-only master plan.** Precise constraints, decisions, and execution cues — not stakeholder prose.

## Intent

The outcome that should exist after this ships.

## Current State

What exists today (product, code, gaps, failure modes).

## Target Behavior

What should change for user, system, or operator.

## Scenarios

> 1. Concrete actor, situation, needed outcome.
> 2. Workflows, edges, failures, permissions, state transitions.

## Acceptance Criteria

- [ ] Observable criterion
- [ ] Observable criterion

## Scope

In:

- Included work

Out:

- Excluded work

## Key Decisions

- Confirmed decision

## Assumptions

- Assumption that affects scope or behavior if wrong

## Implementation Notes

Surfaces, contracts, constraints, risks, sequencing. Avoid brittle file lists.

## Test Strategy

Nearest useful behavioral boundaries from repo patterns.

## Open Questions

- Question that materially affects scope, behavior, or implementation
