# Record a demo

Use [Capture](../../capture/SKILL.md) for visual evidence, including raw recordings and polished
walkthroughs. Follow its preflight, capture, rendering, and verification instructions. It uses the
same agent-browser native recorder for both outputs. Preserve raw footage, screenshots, hashes,
and provenance. Screenshot-only proof uses the same tool. Screenshots do not replace required video.

Deliver the video through the active Devin session's supported artifact or file upload tool and verify that the user can open it. Do not assume local Markdown paths render in chat. For a PR, upload
through a supported artifact flow and link the durable result. Local paths do not work for remote
reviewers. Keep recordings after session cleanup.
